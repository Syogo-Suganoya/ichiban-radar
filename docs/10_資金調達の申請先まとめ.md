# 資金調達の申請先まとめ

調査日：2026-08-14
事業形態：**個人事業主**（法人ではない）
関連：[3_事業・資金計画書](3_一番くじ在庫マップ_事業・資金計画書.md)／[6_収益計画書](6_一番くじ在庫マップ_収益計画書.md)／[7_クラウドファンディング本文ドラフト](7_クラウドファンディング本文ドラフト.md)

> ⚠️ **金額・要件・締切は年度ごとに変わります。** 本書は調査時点の要約であり、**申請前に必ず公式の公募要領で確認してください。** 特に補助金は、同じ名前でも回によって対象経費が変わります。

---

## 0. 結論：この順で当たる

| 優先 | 申請先 | 種別 | 規模感 | 返済 |
| :--: | :--- | :--- | ---: | :--- |
| **1** | **日本政策金融公庫**（新規開業・スタートアップ支援資金） | 融資 | 数百万〜 | あり |
| **2** | **東京都 創業助成事業** | 助成金 | 上限400万円 | なし |
| **3** | **CAMPFIRE**（購入型クラウドファンディング） | 支援金 | 数十万〜 | なし |
| **4** | **小規模事業者持続化補助金** | 補助金 | 50万〜250万円 | なし |
| 5 | 都・区の制度融資（信用保証協会付き） | 融資 | 上限3,500万円 | あり |
| — | デジタル化・AI導入補助金 | 補助金 | 5万〜450万円 | なし | 

**公庫を先頭に置く理由は、確実性と速さです。** 補助金は採択されなければゼロですが、融資は審査に通れば実際に現金が入ります。そして後述のとおり、**補助金は原則あと払いなので、先に立て替える現金が要ります。**

**AI補助金には期待しないでください。** 詳しくは §6 に書きますが、**このプロジェクトはおそらく対象外**です。

## 1. 日本政策金融公庫 ★最優先

**新規開業・スタートアップ支援資金**（旧・新規開業資金）

| 項目 | 内容 |
| :--- | :--- |
| 対象 | 新たに事業を始める人、または**事業開始後おおむね7年以内** |
| 担保・保証人 | **原則不要** |
| 金利 | 無担保で年3.25〜4.65%（2026年3月時点）。**創業期は一律0.65%引下げ**があり、条件次第で年2%台前半まで下がる |
| 法人/個人 | **個人事業主でも利用可** |

**個人開発者にとって、事実上ここが本命です。** 無担保・無保証で借りられる公的融資はほぼここしかありません。

### 通すために効くこと

**自己資金の額が見られます。** 全額を借りる計画より、いくらか自分で出しているほうが通りやすくなります。

**このプロジェクトには有利な材料があります。**

- 事業計画・技術仕様・収益計画が**すでに文書化されている**（[docs/](.) 一式）
- **動くものがある**（モックデータとはいえ画面が動く）
- コスト構造を数字で説明できる（X APIの従量課金・損益分岐点）

**逆に弱いのは「実績ゼロ」です。** だからこそ、実測値（店舗特定率）が出てから申請するほうが説得力が上がります。

> ⚠️ **借金です。** 助成金と違い返済義務があります。[収益計画書](6_一番くじ在庫マップ_収益計画書.md)の保守シナリオ（MAU 1万・転換率1%）は赤字なので、**その場合でも返せる額に抑えてください。**

## 2. 東京都 創業助成事業 ★金額が大きい

公益財団法人 東京都中小企業振興公社

| 項目 | 内容 |
| :--- | :--- |
| 助成額 | **上限400万円 / 下限100万円**、助成率 **2/3以内** |
| 対象 | 都内で創業予定の個人、または**創業から5年未満** |
| 対象経費 | **賃借料・広告費・器具備品購入費・産業財産権出願費・専門家指導費・従業員人件費・委託費（市場調査）** |
| 申請 | Jグランツ（電子申請）→ 書類審査 → **面接審査** → 総合審査 |
| 採択率 | **15%前後** |

**返済不要で400万円は、この規模の事業では極めて大きいです。** 一方で**採択率15%は狭き門**で、面接審査もあります。

### このプロジェクトとの相性

**「広告費」と「委託費（市場調査・分析費）」が効きます。**

- 広告費 … 公開後の利用者獲得
- 委託費 … **オペレーターの電話確認は「市場調査」として説明できる可能性**があります（要確認）

⚠️ **対象は「都内」での創業です。** 事業所（＝個人事業主の場合は原則、開業届に書いた住所）が都内である必要があります。都外なら、お住まいの自治体に同種の制度がないか確認してください。

⚠️ **X APIの利用料が対象になるかは要確認です。** 対象経費の並びに「システム利用料」が無いため、通らない可能性があります。**ここが通らないと、このプロジェクト最大の変動費が助成対象から外れます。**

## 3. CAMPFIRE（購入型クラウドファンディング）

本文ドラフトは [7_クラウドファンディング本文ドラフト](7_クラウドファンディング本文ドラフト.md) にあります。

| 項目 | 内容 |
| :--- | :--- |
| 手数料 | **合計22%**（プラットフォーム17% + 決済5%） |
| 方式 | All-or-Nothing（未達なら不成立・手数料もゼロ）／ All-in（未達でも受取・手数料は発生） |
| Makuake | 手数料22%（税込）でほぼ同水準 |

### 手数料22%は資金計画に必ず織り込む

**100万円集まっても、手元に残るのは約78万円です。** さらにリターン（プレミアムプラン1年間無料など）の原価もかかります。目標額は「必要額 ÷ 0.78」で逆算してください。

### 金額以外の価値のほうが大きいかもしれません

- **公開前に需要があるかを検証できる**（集まらなければ、それ自体が答え）
- **最初のユーザーが手に入る**。SNSデータが薄い立ち上げ期に、実際に使ってくれる人がいるかは死活問題です
- 公庫・助成金の面接で「支援が集まった」と示せる

> ⚠️ **実測値が出る前に公開しないでください。** 店舗特定率が分からないまま「AIが在庫を可視化します」と募って、後から成立しないと分かった場合、**返金では済まない信用の問題**になります。

## 4. 小規模事業者持続化補助金

| 項目 | 内容 |
| :--- | :--- |
| 対象 | **商業・サービス業は常時使用する従業員5人以下**（個人事業主を含む） |
| 補助額 | 通常枠 上限50万円、特例活用で**最大250万円** |
| 補助率 | **2/3**（赤字事業者は3/4） |
| 直近の締切 | 第20回：**2026年12月15日** |
| 創業型 | 開業直後でも申請できる枠があります |

**個人事業主にとって最も間口が広い補助金です。** 従業員がいなくても申請できます。

⚠️ **ウェブサイト関連費には上限があります**（過去回では補助額の1/4まで）。**ウェブ開発費だけで満額は狙えません。** 第20回では広報費・ウェブサイト関連費の扱いが見直されているので、公募要領で必ず確認してください。

⚠️ 商工会議所・商工会の**「事業支援計画書」が必要**です。発行に時間がかかるので、締切間際に動くと間に合いません。

## 5. 制度融資（東京都・区市町村）

東京都中小企業制度融資「創業」

| 項目 | 内容 |
| :--- | :--- |
| 融資限度額 | **3,500万円** |
| 期間 | 設備10年以内／運転7年以内（据置1年以内） |
| 対象 | 創業予定者、または**創業5年未満** |
| 特徴 | 信用保証料の補助あり。**「創業経営者保証不要型」**もある |

**公庫と併用できます。** ただし信用保証協会の保証が要るぶん、公庫より手続きは重くなります。

**区市町村レベルにも独自の制度があり、利子補給（利息の一部を自治体が負担）が付くことがあります。** 事業所のある区の産業振興課に問い合わせるのが早いです。

## 6. デジタル化・AI導入補助金（旧・IT導入補助金）── ⚠️ おそらく対象外

2026年に「IT導入補助金」から名称変更。補助額は5万〜450万円で、生成AIのクラウド利用料が最大2年分まで対象になりました。

**名前だけ見ると本命に見えますが、このプロジェクトは対象外の可能性が高いです。**

**この補助金は「既製のITツールを導入する」費用が対象**で、対象になるのは**事務局に登録されたITツール**です。自社サービスを開発する費用は対象になりません。

| | |
| :--- | :--- |
| 対象になるもの | 登録済みの会計ソフト・AIチャットボット・AI-OCR などの**導入費** |
| このプロジェクト | **自分でAIサービスを作る**。Gemini API も X API も「登録ITツール」ではない |

**「AIを使う事業だからAI補助金」ではありません。** ここは期待とのズレが大きいので、時間を使う前に対象要件を確認してください。

> なお、業務効率化のために市販のAIツールを導入するなら対象になりえますが、**それは本プロジェクトの資金調達ではありません。**

## 7. 落とし穴（先に知っておくべきこと）

### ① 補助金・助成金は「あと払い」

**採択されても、すぐにお金は入りません。** 事業を実施し、経費を**自分で支払い**、実績報告して検査を受けてから交付されます。

**つまり、全額を立て替える現金が必要です。** これが「公庫を先に」と書いた最大の理由です。融資で手元資金を作り、それを使って補助金事業を回すのが現実的な順序になります。

### ② GビズIDプライムの取得に時間がかかる

補助金の電子申請（Jグランツ）には **GビズIDプライム** が要ります。取得には**2週間程度**かかるので、公募開始を見てから動くと間に合いません。**今すぐ申請しておくのが正解です。**

### ③ 同じ経費を二重に受け取ることはできない

**同一の経費に複数の補助金は使えません。** 「広告費は東京都、システム費は持続化」のように**経費を分けて申請**する設計が要ります。

### ④ 開業届を出していないと始まりません

**個人事業主としての開業届**（税務署）が前提になる制度がほとんどです。まだなら最初に済ませてください。青色申告承認申請書も同時に出しておくと節税になります。

### ⑤ 採択率を織り込む

東京都創業助成は**15%前後**です。**1つに賭けず、複数を並行して仕込んでください。**

### ⑥ 事業の性質上のリスクを聞かれる

**「一番くじ」は他社の登録商標で、本サービスは非公式です。** 面接でここを突かれる可能性は高いので、[README](../README.md) の注意事項と同じ説明を用意しておいてください。権利者からの申し入れがあった場合にどうするか、答えられるようにしておくと強いです。

## 8. 進め方（案）

| 時期 | やること |
| :--- | :--- |
| **今すぐ** | 開業届／青色申告承認申請／**GビズIDプライム申請**（2週間かかる） |
| **実測前** | 公庫の面談予約、区の産業振興課へ相談。説明資料は [docs/](.) を流用 |
| **実測後** | **店舗特定率が出てから**、事業計画の数字を確定させる |
| 実測後 | 公庫へ申請 → 手元資金を作る |
| 並行 | 東京都創業助成の公募時期を確認して申請 |
| 資金確保後 | CAMPFIRE 公開（**数字の裏付けができてから**） |
| 年内 | 小規模事業者持続化補助金 第20回（締切 2026-12-15） |

**「実測後」を軸にしているのは、店舗特定率が出るまで事業計画の数字がすべて暫定値だからです**（[docs/4](4_一番くじ在庫マップ_データ収集実現可能性調査.md)）。暫定値で申請して、あとから前提が崩れるほうが痛手になります。
