# 企画書：『一番くじ リアルタイム在庫推測マップ』

> 改訂 2026-08-13（第2版）
> 主な変更点：①データ収集ロジックをX APIのクエリ長制限に合わせて再設計 ②Instagramを補助ソースとして追加 ③課題対策にコスト制御を追記
> 前提調査：[4_一番くじ在庫マップ_データ収集実現可能性調査.md](4_一番くじ在庫マップ_データ収集実現可能性調査.md)

## 1. 企画概要
本サービスは、X（旧Twitter）等のSNSに投稿されるリアルタイムな「生声データ」をAIで自然言語処理・解析し、コンビニエンスストアや書店等における「一番くじ」のリアルタイムな在庫ステータス（品切れ・品薄・十分等）を可視化する地図型プラットフォームです。

金融業界で用いられる**「SNSやニュースのテキストから株価反応を予測する技術（オルタナティブデータ分析）」**に着想を得ており、非構造化テキストデータから現実世界の定量的状態（在庫残数）を高精度に推測・可視化します。

---

## 2. 着想の背景（なぜ株価予測のアプローチなのか）

### ① 金融（株価反応予測）における手法
株式市場では、IR発表や公式ニュース（公式データ）だけでなく、SNS上の個人投資家の反応や掲示板の感情データ（オルタナティブデータ）をLLMでセンチメント分析し、株価の短期的な動向やボラティリティを推測する手法が実用化されています。

### ② 一番くじ市場への応用可能性
一番くじ市場においても同様の構造が存在します。
* **公式データ（公式店舗検索・POS）**: 更新遅延があり、特にコンビニエンスストア等ではリアルタイムの「残りくじ枚数」や「完売フラグ」がほぼ提供されない。
* **ユーザーの生声（SNS投稿）**: 「〇〇店でラストワン狙った」「完売ポスター貼ってあった」「残り5枚だった」など、極めて新鮮かつ具体的な「店舗センシングデータ」が毎分投稿されている。

**「分散するSNS投稿（テキスト）をリアルタイムで収集・感情分析し、現実の数値・状態（在庫・株価）に変換してマップ上にプロットする」**という株価予測のアルゴリズム構造をそのままエンタメ消費市場に応用できる点に着目しました。

## 3. 解決する課題（ペインポイント）

1. **ファン（ユーザー）の課題**
   * お目当ての商品（特に上位賞やラストワン賞）を求めて何店舗もハシゴ（徒労）してしまう。
   * 店舗への電話問い合わせは店舗側の負担になるため控えたいが、現地に行かないと分からない。
2. **店舗側の課題**
   * 「在庫ありますか？」という電話問合せの対応に追われ業務が圧迫される。

## 4. システム構造・ロジック

### ① データインジェクション（データ収集）

**X（一次ソース）**
* X API v2 を利用し、`一番くじ` × 状態語（`完売|売り切れ|残り|ラストワン|引いてき|入荷`等）をリアルタイム監視・収集。
* ⚠️ **店舗名をクエリに列挙する方式は採らない。** X APIの検索クエリは512文字上限のため、店舗名を並べると即座に超過する。**店舗の特定は後段のAIが本文から抽出する**設計とする。
* RT除外（`-is:retweet`）と差分取得（`since_id`）を必須要件とする（従量課金のため取得件数＝原価）。

**Instagram（補助ソース・Phase 2以降）**
* Instagram Graph API のハッシュタグ検索（`#一番くじ` `#〇〇一番くじ` 等を個別指定）で収集。**API利用料は無料。**
* 「どの作品がどのエリアで動いているか」の面的トレンド把握と、Xで拾えなかった店舗の補完に用いる。
* 制約：30ユニークタグ/7日、直近24時間の投稿のみ、App Review承認が必要。

### ② AIセンチメント＆コンテキスト判定（推測エンジン）
LLM（Google Gemini）を用いて投稿文章を構造化し、ステータス判定を行います。Instagramの投稿はキャプションに店舗名がないことが多いため、画像のVision解析を併用します。

* **入力例**: 「〇〇駅前のローソン、ラストワン賞まであと3枚だった！」
* **AI推測**: `【対象店舗】〇〇駅前店` / `【ステータス】品薄（極少）` / `【確信度】高` / `【タイムスタンプ】10分前`

### ③ ステータス定義とマッププロット
地図API（Google Maps等）上に店舗ピンをステータス別に色分け表示します。

| ステータス | ピン色 | 判定基準・投稿テキスト例 |
| :--- | :--- | :--- |
| **完売** | 🔴 赤 | 「完売ポスター出てた」「売り切れ」等 |
| **品薄** | 🟠 オレンジ | 「残りわずか」「ラストワンまであと〇枚」「上位賞なし」等 |
| **十分** | 🟢 緑 | 「入荷したばかり」「くじ箱フルだった」等 |
| **情報不足** | ⚪ グレー | 直近（例: 12時間以内）に該当店舗に関する投稿がない |

## 5. ビジネスモデル（マネタイズ案）

詳細は [6_収益計画書](6_一番くじ在庫マップ_収益計画書.md) を参照。

> **前提**：ログインは**任意**。未ログインでも地図・店舗詳細・A賞フィルタは使える。ログインで増えるのは「お気に入り」と「在庫急変の通知」だけ。

1. **① 広告収入**
   * 未ログイン層を含む全員に広告を表示し、母数から薄く回収する
   * 1人あたり月間収益は約2.4円。これ単体では黒字化しない
   * ⚠️ **転売・二次流通の広告はカテゴリブロックを必須運用**（信頼性と権利者との関係を守るため）
2. **② プレミアムプラン（月額390円 / 年額3,900円）— 収益の主柱**
   * **お気に入り店舗の登録**と**在庫急変のプッシュ通知**（品薄・完売・上位賞が消えた瞬間）
   * 有料会員1人あたり約376円。**有料転換1人＝無料ユーザー約160人分**
   * **無料機能を人質に取らない**のが要点。地図を見たいだけの人は登録せずに使えるので離脱しない
3. **③ B2B（店舗・メーカー向け）**
   * アニメショップやドラッグストア等への掲載枠（月1〜3万円/店舗）
   * ユーザー数に依存しない安定収益。**5店舗の契約でβ版の運営費を賄える**

> **収益構造の要点**：X APIの費用は**ユーザー数ではなく監視範囲（エリア×タイトル数）に比例**するため、**ユーザーが1人増えたときの追加コストはほぼゼロ**。β版の損益分岐は約9,100MAU。

## 6. 開発ロードマップと課題対策

### 主な課題と解決アプローチ
* **X APIのコスト（2026年2月に従量課金へ移行、$0.005/投稿）**
  * 取得件数がそのまま原価になるため、**費用管理はシステム要件として実装する**（支出上限の設定、日次消費の記録、予算超過時の自動停止）。
  * 対策：RT除外・状態語ANDによるクエリ絞り込み、時間帯別のポーリング頻度制御、信頼度の高い「一番くじ報告アカウント」の重点モニタリング。
  * 中長期：**無料のInstagram**の比率を高め、有償API依存度を下げる。
* **情報の誤り・フェイク情報**
  * 対策：AIによる文脈判定（不自然な投稿の除外）に加え、複数投稿のタイムスタンプ重なりによるスコアリング（クロス検証）を実施。
  * マップ上では「AI推測」と「電話確認済み（確定情報）」をバッジで明示し、推測である旨の免責を常時表示する。
* **データ取得のコンプライアンス**
  * 公式API（X API / Instagram Graph API）のみを使用し、規約違反となるスクレイピングは一切行わない。

### フェーズ計画
* **Phase 1（PoC・検証）**: 特定の超人気タイトル（例：ドラゴンボール、ハイキュー等）発売日に限定し、都内特定のエリアでXデータ取得とAI推測の精度検証を実施（X API費用は約4,000円）。**並行してInstagramのApp Reviewを申請**し、承認待ち期間を先行消化する。
* **Phase 2（β版リリース）**: Webアプリとしてマップ表示機能をリリースし、ユーザー体験を検証。Instagram（承認後）を追加。AdSense申請、プレミアムプラン開始（プッシュ通知の実装完了が条件）、B2B営業を開始。
* **Phase 3（正式運用・マネタイズ）**: 対応エリア拡大と、他グッズ（トレカ、ガチャガチャ）へのカテゴリ横展開。
