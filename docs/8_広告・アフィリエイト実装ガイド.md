# 広告・アフィリエイト 実装ガイド

作成 2026-08-13
関連：[6_収益計画書](6_一番くじ在庫マップ_収益計画書.md)

---

## 0. なぜこの文書が要るのか

**一般ユーザー向け画面にログインを作らない**方針にしたため、サブスクリプション課金ができなくなりました。会員を識別できない以上、月額課金は成立しません。

その結果、**収益は「広告」と「B2B」に一本化**されました。この文書は、そのうち広告・アフィリエイトをどう入れるかの手順書です。

> ⚠️ **先に結論**：広告だけでは黒字になりません。詳細は[収益計画書](6_一番くじ在庫マップ_収益計画書.md)ですが、広告の1人あたり月間収益は約2.4円で、損益分岐には約38,000MAUが必要です。**B2B（店舗掲載枠）を主軸に据えることが前提**で、広告はその補助と位置づけてください。

---

## 1. 収益源の3階層

| # | 種別 | 位置づけ | 単価の傾向 |
| :-- | :--- | :--- | :--- |
| ① | **ディスプレイ広告**（Google AdSense等） | 面を自動で埋める土台。手離れが良い | 低（eCPM 100〜400円） |
| ② | **アフィリエイト**（ASP経由） | 文脈が合えば単価は高いが、**本サービスとの相性は限定的**（後述） | 中 |
| ③ | **B2B掲載枠**（直接契約） | **実質的な主軸**。店舗・メーカーとの直接取引 | 高（月1〜3万円/店舗） |

### アフィリエイトの相性について、正直な評価

本サービスの利用者は「**いま近くの店で買いたい**」人です。ネット通販で買いたい人ではありません。この動機のズレがあるため、**通販アフィリエイトのコンバージョンは構造的に低く出ます**。

期待できるのは次のような周辺需要です。

- 発売前の**予約**（あみあみ・駿河屋・プレミアムバンダイ等）
- くじで当たらなかった賞の**単品購入**（※二次流通の扱いは3-3参照）
- 関連グッズ・保護ケース・ディスプレイ用品

**「アフィリエイトで稼ぐ」という前提で計画を立てないでください。** 補助的な上乗せです。

## 2. 提携先の候補

### 2-1. ASP（アフィリエイト・サービス・プロバイダ）

| ASP | 特徴 | 本サービスでの用途 |
| :--- | :--- | :--- |
| **[A8.net](https://www.a8.net/)** | 国内最大手。登録サイト数・案件数ともに最多。**サイト審査がない**ため最初の1社に向く | まずここで案件の相場観を掴む |
| **[もしもアフィリエイト](https://af.moshimo.com/)** | 個人向けの支援が手厚い。Amazon・楽天の提携が通りやすく、**W報酬制度**（成果報酬に上乗せ）がある | Amazon・楽天のリンクはここ経由が有利 |
| **[バリューコマース](https://www.valuecommerce.ne.jp/)** | Yahoo!ショッピング・楽天・Amazonなど大手案件に強い。**平均承認率とEPCを全会員が確認できる**ため費用対効果を判断しやすい | 成果が出始めてから精査に使う |
| **[afb（アフィb）](https://www.afi-b.com/)** | 報酬の消費税分が上乗せされる。支払サイトが早い | 補助 |

> **審査の目安**：バリューコマースは審査があり、コンテンツ量が少ないと落ちます。**7〜10ページ程度の実質的なコンテンツ**が用意できてから申請するのが無難です。A8.netは審査がないので先に登録して案件を見られます。

### 2-2. ホビー系の個別プログラム

| 提携先 | 経路 | 備考 |
| :--- | :--- | :--- |
| **[駿河屋](https://affiliate.suruga-ya.jp/)** | 自社プログラム（直接申請） | ランクに応じて報酬率が上がる仕組みあり。**中古・二次流通を多く扱う**点は要判断 |
| **あみあみ** | ASP経由 | 国内最大級のホビー通販。新品予約が中心で相性は比較的良い |
| **プレミアムバンダイ** | ASP経由 | 権利者（BANDAI SPIRITS）系。**公式との誤認**に最も注意が必要 |
| **Amazonアソシエイト** | もしもアフィリエイト経由が有利 | 報酬率は低いが成約しやすい |
| **楽天アフィリエイト** | 直接／もしも経由 | 同上 |
| **アニメイト** | ASP経由 | 実店舗の在庫表示と文脈が近い |

## 3. ⚠️ このサービス特有の禁止事項

### 3-1. 転売・二次流通の広告をブロックする

**最優先の運用ルールです。**

一番くじの在庫マップに転売品の広告が出れば、次の3つを同時に失います。

1. **ユーザーの信頼**（転売を助長するサービスと見なされる）
2. **権利者との関係**（BANDAI SPIRITSは転売対策を明示している）
3. **店舗との関係**（売り場の敵になる）

**対策**

- AdSense の**広告カテゴリブロック**で、オークション・フリマ・二次流通系を除外する
- アフィリエイトは**個別案件ごとに手動で提携**し、自動出稿にしない
- **月1回、実際に配信されている広告を自分の目で確認する**（設定だけでは漏れる）

### 3-2. 公式と誤認させない

プレミアムバンダイ等の権利者系案件を扱う場合、**本サービスが公式・公認であるかのような文脈**に置かないでください。「一番くじ」は株式会社BANDAI SPIRITSの登録商標です。

### 3-3. 中古・二次流通を扱うショップの判断

駿河屋のように中古も扱うショップは、**新品・予約の案件に限定して提携**するのが安全です。ショップ単位で一律に貼らないでください。

## 4. 【必須】ステマ規制への対応

2023年10月1日から、景品表示法の告示により**ステルスマーケティングが不当表示として規制**されています。2026年現在も消費者庁の執行は活発です。

### やること

**アフィリエイトリンクを含むページには、「PR」「広告」「アフィリエイト広告」のいずれかを、一般消費者が分かりやすい位置に明記する。**

| 項目 | 内容 |
| :--- | :--- |
| **表記の場所** | ページ**上部**（スクロールせずに見える位置）。フッターの隅や、折りたたみの中は不可 |
| **表記の文言** | 「PR」「広告」「アフィリエイト広告」。**「アフィ」「Sponsored」等の略語・英語は避ける** |
| **文字サイズ** | 本文と同等以上。背景に埋もれる配色は不可 |
| **対象** | アフィリエイトリンクを含むページ。ディスプレイ広告（AdSense）は広告と判別できるため原則対象外だが、**紛らわしい配置は避ける** |

> **法的責任の所在**：景品表示法の規制対象は原則として広告主（商品を供給する事業者）ですが、**媒体側が不適切な表示をすれば広告主から提携を切られます**。自衛のためにも表記は徹底してください。

### 実装（本アプリの場合）

現状、地図画面の下部に広告枠があります。**アフィリエイトリンクを置く場合は、その枠の直上に「PR」ラベルを常時表示**してください。ディスプレイ広告のみの場合も「広告」表記を残す方が安全です（現在の実装は「広告」表記あり）。

## 5. Google AdSense の導入手順

### 5-1. 申請前に満たすべき条件

| 条件 | 本プロジェクトの状況 |
| :--- | :--- |
| 18歳以上・Googleポリシー準拠のコンテンツ | ○ |
| **サイトのHTMLソースにアクセスできる** | ○（Next.js） |
| **独自ドメイン** | ⏳ 未取得 |
| **オリジナルで価値のあるコンテンツ** | △ 地図アプリ単体では「コンテンツが少ない」と判断されうる。**LP＋説明ページ＋プライバシーポリシー等を揃える** |
| プライバシーポリシー | ❌ 未作成（**必須**） |
| 運営者情報・問い合わせ先 | ❌ 未作成（**必須**） |

> ⚠️ **地図アプリは審査で不利になりやすい**カテゴリです。「ユーザーに付加価値を提供しないドメイン」と見なされないよう、**サービス説明・使い方・よくある質問などの読み物ページ**を用意してから申請してください。

### 5-2. ads.txt の設置

`ads.txt` は必須ではありませんが、**偽の広告枠に収益が流れるのを防ぐ**ため設置を強く推奨します。

Next.js では `web/public/ads.txt` に置くだけで `https://example.com/ads.txt` として配信されます。

```
google.com, pub-0000000000000000, DIRECT, f08c47fec0942fa0
```

### 5-3. 広告スクリプトの読み込み

`next/script` を使い、`strategy="afterInteractive"` で読み込みます。地図の初期表示を遅らせないためです。

```tsx
// web/src/app/layout.tsx
import Script from "next/script";

<Script
  async
  src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-XXXX"
  crossOrigin="anonymous"
  strategy="afterInteractive"
/>;
```

### 5-4. レイアウトシフト（CLS）対策

**広告枠の高さを先に確保してください。** 後から広告が挿入されて地図が飛ぶと、体験が大きく劣化します。

現在の実装（`AppShell.tsx` 下部の広告枠）は固定高さのプレースホルダになっているので、**その高さを広告サイズに合わせる**形で差し替えてください。

## 6. 進め方（推奨順）

1. **独自ドメインを取得**
2. **プライバシーポリシー・運営者情報・問い合わせ窓口を作る**（AdSense申請の前提であり、店舗からの苦情窓口も兼ねる）
3. **サービス説明・使い方などの読み物ページを追加**（審査対策）
4. **A8.net に登録**して案件の相場を見る（審査なし）
5. **AdSense を申請**
6. 承認後、**広告カテゴリブロックを設定**（3-1）→ 実配信を目視確認
7. もしもアフィリエイト／バリューコマースに申請（コンテンツが揃ってから）
8. ホビー系の個別案件に提携申請（**新品・予約に限定**）
9. **B2B（店舗掲載枠）の営業を開始** ← 本命
